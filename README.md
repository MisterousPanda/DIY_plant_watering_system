# See-the-sip

A bench guide for a four-pot Raspberry Pi watering kit: one 12 V peristaltic pump per pot, a food-grade HDPE reservoir, capacitive soil sensors, and plain water.

The guide is the site. The Raspberry Pi is the controller.

```bash
npm install
npm run dev
```

Shelf prices on the parts list were fetched on 2026-10-11.
